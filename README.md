# 1.20.1 Bedwars Plugin (Paper 1.20.1)

完整的起床战争插件，支持4队和8队模式，包含Hypixel风格的功能和多房间竞技场系统。

## 版本

当前版本：v0.1.0

## 🌍 多语言支持

插件支持**完整的多语言配置系统**，所有游戏内文本都可以轻松翻译和定制！玩家可以根据自己的偏好选择语言。

### 当前支持语言
- 🇭🇰 繁體中文 (zh_TW) - **默认**
- 🇨🇳 简体中文 (zh_CN) - **新增！**
- 🇺🇸 English (en_US)
- 其他语言可轻松添加

### 如何切换语言

**方法一：使用命令（任何玩家）**
```bash
/bw language <语言代码>
# 例如:
/bw language zh_TW    # 繁体中文
/bw language zh_CN    # 简体中文
/bw language en_US    # English
```

**方法二：查看可用语言**
```bash
/bw language   # 列出所有可用的语言
```

**方法三：编辑配置文件（管理员）**
1. 编辑 `config.yml` 文件
2. 修改配置项：`language: "zh_CN"`（改为需要的语言代码）
3. 重启服务器

### 为何选择简体中文？

现在插件同时支持繁体中文（zh_TW）和简体中文（zh_CN），玩家们可以：
- 点击命令快速切换语言
- 所有菜单、消息实时更新
- 不需要重启服务器
- 每个玩家可以有自己的语言偏好

### 自定义消息

1. **编辑配置文件** - 修改 `plugins/Bedwars/languages/messages_zh_CN.yml` 或其他语言文件
2. 例如要改变"队伍选择"的文本：
   ```yaml
   gui:
     team-select: "你的自定义文本"
   ```
3. 编辑后执行 `/bw reload` 重载配置

### 添加新语言

1. 在 `plugins/Bedwars/languages/` 下复制 `messages_en_US.yml`
2. 重命名为 `messages_<语言代码>.yml`（例如：`messages_ja_JP.yml` 为日文）
3. 翻译所有文本
4. 玩家可以立即使用 `/bw language ja_JP` 切换到新语言

### 消息组织结构

所有消息按以下分类组织：
```
gui:                 # 菜单界面文本
  maps
  map-editor
  team-select
  ...
command:            # 命令反馈消息
game:               # 游戏内事件消息
misc:               # 杂项文本
```

## 功能特色

### 核心游戏功能
- ✅ **多队伍支持**: 4队模式（SQUAD）和8队模式（SOLO/DOUBLES）
- ✅ **床破坏机制**: 床被破坏后无法重生
- ✅ **资源生成器**: 铁/金/钻石/绿宝石四种资源
- ✅ **商店系统**: 方块、武器、护甲、工具、特殊物品、队伍升级
- ✅ **队伍升级**: 陷阱、分矿升级、治疗池、防御强化
- ✅ **玩家升级**: 疾跑、防御强化

### Hypixel风格功能
- 🏆 **连杀系统**: 击杀 2/5/10 人获得特殊奖励
- 💥 **床破坏特效**: 烟花+粒子效果+音效
- 👻 **观察者指南针**: 死亡后传送到其他玩家
- 🔄 **重连保护**: 30秒内重连保留状态
- ⚡ **突然死亡**: 游戏后期自动移除床

### 多房间系统
- 🎮 **竞技场系统**: 支持多个游戏同时进行
- 🔄 **队列匹配**: 自动匹配玩家到合适的房间
- 🗳️ **地图投票**: 玩家投票选择下一张地图
- 📊 **统计系统**: 记录击杀/死亡/床破坏/胜利数据
- 🏆 **排行榜**: 大厅显示顶级玩家

### 地图管理
- 🗺️ **自动地图保存**: 游戏结束后自动恢复地图
- ⚒️ **WorldEdit集成**: 使用木斧快速选择地图区域
- 🎯 **单模式系统**: 每张地图只能有一个游戏模式
- 📝 **GUI设置**: 完整的图形界面地图编辑器

## 环境要求

- **服务器**: Paper 1.20.1 或更高版本
- **Java**: 17 或更高版本
- **Gradle**: 8.5（已包含wrapper）
- **可选依赖**: WorldEdit 7.2.15+（用于快速地图设置）

## 安装步骤

1. **编译插件**
   ```bash
   ./gradlew build
   ```
   编译完成的jar文件位于 `build/libs/` 目录

2. **安装插件**
   - 将 `.jar` 文件放入服务器的 `plugins/` 目录
   - （可选）安装 WorldEdit 插件以使用快速区域选择功能

3. **启动服务器**
   - 首次启动会自动生成配置文件
   - 配置文件位于 `plugins/Bedwars/`

## 管理员命令

### 基础命令
- `/bw` - 传送到 Bedwars 大厅
- `/bw gui` - 打开地图设置GUI（管理员专用）
- `/bw reload` - 重载配置
- `/bw setlobby` - 设置主大厅出生点

### 队列管理命令
- `/bw queue <地图名> [模式]` - 加入指定地图的队列
- `/bw quickjoin` - 快速加入任意可用游戏
- `/bw arenas` - 查看所有竞技场状态
- `/bw queues` - 查看所有队列状态
- `/bw leave` - 离开当前游戏或队列

### 游戏控制命令（仅限管理员）
- `/bw start` - 立即开始游戏（跳过倒计时）
- `/bw stop` - 强制结束游戏

### 其他命令
- `/bwshop` - 打开商店（游戏内使用）
- `/stats [玩家名]` - 查看统计数据

## 地图设置详细教程

### 1. 创建新地图

1. 使用 `/bw gui` 打开设置GUI
2. 点击 **"Create Map"** 创建新地图
3. 在聊天栏输入地图名称（只能使用字母、数字、下划线和横杠）

### 2. 基础设置

打开地图编辑器后，你会看到以下选项：

#### 📍 设置大厅出生点（Lobby Spawn）
- 站在想要的位置
- 点击 **"Set Lobby"** 按钮
- 玩家进入游戏时会在此位置等待

#### 🗺️ 设置地图边界（Arena Bounds）

**方法一：手动设置**
1. 点击 **"Manual Bounds"** 按钮
2. 站在地图的一个角落，在聊天栏输入 `pos1`
3. 站在地图的对角位置，在聊天栏输入 `pos2`
4. 系统会显示区域大小并保存

**方法二：使用WorldEdit（推荐）**
1. 点击 **"WorldEdit Select"** 按钮
2. 使用 `//wand` 获取木斧
3. 左键点击第一个点，右键点击第二个点
4. 在聊天栏输入 `ok` 确认选区
5. 系统会自动导入选区并保存

#### 🎮 选择游戏模式
- 点击 **"Mode Selector"** 按钮
  - **左键**: 4队模式（SQUAD - 4人/队，共4队）
  - **右键**: 8队模式（SOLO - 1人/队，共8队）

### 3. 队伍设置

点击 **"Teams"** 按钮进入队伍设置界面。

#### 4队模式队伍
- 🔴 红队（RED）
- 🔵 蓝队（BLUE）
- 🟢 绿队（GREEN）
- 🟡 黄队（YELLOW）

#### 8队模式队伍
除了上述4队，还包括：
- 🟦 青队（AQUA）
- ⚪ 白队（WHITE）
- 🟣 粉队（PINK）
- ⚫ 灰队（GRAY）

#### 为每个队伍设置：

1. **队伍出生点（Team Spawn）**
   - 站在出生位置
   - 点击 **"Set Spawn"**
   - 玩家重生会出现在此位置

2. **队伍床位置（Team Bed）**
   - 站在床的位置
   - 点击 **"Set Bed"**
   - 游戏开始时会自动放置对应颜色的床

3. **基地生成器（Base Generator）**
   - 站在生成器位置
   - 点击 **"Set Generator"**
   - 会生成铁锭和金锭

4. **商店NPC（Shop NPC）**
   - 站在商店位置
   - 点击 **"Set Shop"**
   - 会生成村民NPC

### 4. 中立生成器设置

返回主编辑器，点击 **"Middle Generators"**

#### 添加钻石生成器
1. 点击 **"Add Diamond"**
2. 站在想要的位置
3. 点击手中的钻石
4. 重复步骤添加多个生成器

#### 添加绿宝石生成器
1. 点击 **"Add Emerald"**
2. 站在想要的位置
3. 点击手中的绿宝石
4. 重复步骤添加多个生成器

### 5. 保存和激活

1. 点击 **"Save"** 保存地图配置
2. 点击 **"Set Active"** 将此地图设为当前活动地图
3. 地图配置文件保存在 `plugins/Bedwars/maps/<地图名>.yml`

### 6. 设置主大厅

1. 在主世界找到一个合适的位置作为主大厅
2. 站在该位置使用命令 `/bw setlobby`
3. 游戏结束后玩家会返回这个位置

## 游戏玩法

### 加入游戏

**通过命令加入**
```
/bw queue <地图名>     # 加入指定地图
/bw quickjoin          # 快速加入任意游戏
```

**通过NPC加入**
- 右键点击大厅中的NPC
- 在GUI中选择地图
- 选择游戏模式（已简化为每张地图一个模式）

### 游戏流程

1. **等待阶段**
   - 玩家在大厅出生点等待
   - 人数达到最低要求开始倒计时
   - 可以使用 `/bw leave` 离开

2. **游戏开始**
   - 玩家传送到各自队伍出生点
   - 床自动放置在床位置
   - 生成器开始运作

3. **收集资源**
   - 基地生成器：铁锭（1秒/个）、金锭（8秒/个）
   - 钻石生成器：钻石（30秒/个，多人共享升级）
   - 绿宝石生成器：绿宝石（60秒/个，多人共享升级）

4. **商店购买**
   - 右键点击商店NPC打开商店
   - 购买方块、武器、护甲、工具、特殊物品
   - 购买队伍升级（陷阱、分矿升级、治疗池等）

5. **战斗目标**
   - 破坏其他队伍的床
   - 击杀失去床的队伍所有成员
   - 最后存活的队伍获胜

### 特殊机制

#### 连杀奖励
- 2连杀：速度II效果
- 5连杀：速度II + 伤害提升
- 10连杀：速度II + 伤害提升II

#### 游戏事件（自动触发）
- **5分钟**: 钻石生成器 II - 速度提升
- **10分钟**: 绿宝石生成器 II - 速度提升
- **15分钟**: 钻石生成器 III - 速度再提升
- **20分钟**: 绿宝石生成器 III - 速度再提升
- **25分钟**: 突然死亡 I - 所有床自动破坏
- **30分钟**: 游戏结束 - 床存活最多的队伍获胜

#### 重连系统
- 断线后30秒内重连可保留状态
- 超时视为退出游戏

## 常见问题

**Q: 如何更改队伍数量？**
A: 在地图编辑器中点击 "Mode Selector"，左键选择4队，右键选择8队。

**Q: WorldEdit按钮不显示？**
A: 确保服务器已安装WorldEdit插件并正确加载。

**Q: 游戏提前触发突然死亡？**
A: 确保所有队伍的床位置都已正确设置。

**Q: 地图没有恢复？**
A: 检查地图边界是否正确设置（使用Manual Bounds或WorldEdit Select）。

**Q: 如何添加更多地图？**
A: 使用 `/bw gui` 创建新地图，每张地图可以设置不同的模式。

**Q: 玩家游戏结束后回到哪里？**
A: 返回到 `/bw setlobby` 设置的主大厅位置。

**Q: 如何更改语言？**
A: 使用命令 `/bw language <语言代码>`。例如：`/bw language zh_CN` 切换到简体中文。也可以编辑 server.properties 中的 `language` 配置项。

**Q: 支持哪些语言？**
A: 当前支持繁体中文（zh_TW）、简体中文（zh_CN）和英文（en_US）。可以按照文档添加更多语言。

**Q: 如何自定义消息文本？**
A: 编辑 `plugins/Bedwars/languages/messages_<语言代码>.yml` 文件，修改相应的文本，然后执行 `/bw reload` 重载配置。

**Q: 多语言文件在哪里？**
A: 语言文件位于 `plugins/Bedwars/languages/` 目录。首次启动时会自动生成。
